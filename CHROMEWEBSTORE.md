**Extension Name** [REQUIRED]

**Short Description** [REQUIRED]

**Detailed Description** [REQUIRED]
Download and copy high-quality SVG vector icons and stickers directly from Flaticon with a single click.

KEY FEATURES
• Direct SVG Download — Save any standard icon or sticker directly in scalable .svg format without daily limits.
• One-Click "Copy SVG" — Copy clean SVG vector code directly to your clipboard and paste into Figma, Sketch, Adobe XD, or code editors.
• Icon Editor Support — Download customized and recolored vector icons straight from the built-in editor.
• Search Grid Integration — Download SVGs directly from search listings and category cards without opening individual tabs.
• Fast & Lightweight — Operates quietly in the browser without consuming background resources.
• 100% Private & Safe — All downloads and clipboard operations occur locally on your machine. No user tracking or analytics.

HOW TO USE
1. Log into your free Flaticon account at flaticon.com.
2. Browse to any icon or sticker page, or search for your favorite designs.
3. Click the "SVG :)" button to download the vector file instantly, or click "Copy SVG" to copy the vector code directly to your clipboard.
4. Paste the vector graphic into Figma, Illustrator, or your web project.

PRIVACY & SECURITY
This extension does not collect, track, or transmit any personal data or browsing activity. All actions occur entirely on your local machine.

PERMISSIONS
• Access to flaticon.com and flaticon.es: Needed only to display the SVG download buttons and retrieve vector data directly when you click download.
