# Changelog

All notable changes to the **SVG Downloader for Flaticon** extension are documented in this file.

---

## [v0.2.0] - 2026-10-14

### 🚀 Highlights
- **Branding & Visual Refresh**: Redesigned modern icon set generated at pixel-perfect resolutions (16×16, 32×32, 48×48, and 128×128) with transparent background and crisp anti-aliasing.
- **Manifest V3 Optimization**: Updated `manifest.json` with standard match patterns (`https://*.flaticon.com/*`, `https://*.flaticon.es/*`), toolbar action icon, and proper Manifest V3 declarations.
- **Enhanced Discoverability & SEO**:
  - Store and repository name updated to **"SVG Downloader for Flaticon - Free Vector Icons"** compliant with Chrome Web Store trademark policies.
  - Added targeted keywords for Figma designers, web developers, and graphic artists.
- **Direct Privacy Navigation**: Added dedicated `#privacy` and `#pricavy` URL anchors in the documentation for direct compliance links and GitHub navigation.
- **Automated Release Pipeline**: Added release packaging script (`npm run build:zip`) and GitHub Actions workflow for automatic zip distribution on tag push.

### 🛠️ Key Features Included
- **Direct SVG Downloads**: Download scalable `.svg` files from standard icon and sticker detail pages.
- **One-Click "Copy SVG"**: Copy raw vector markup directly to your clipboard to paste into Figma, Sketch, Illustrator, or HTML.
- **In-Browser Editor Support**: Download edited SVG vectors directly after customizing colors or strokes in Flaticon's built-in editor.
- **Search Grid Exporter**: Injects quick SVG download buttons right on the icon cards in search results and related collections.
- **100% Client-Side Privacy**: No tracking, no analytics, no external servers.
